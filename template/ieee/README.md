# HFLab LaTeX Template for IEEE IES

IEEE Industrial Electronics Society (IES) の学会に論文を投稿することを想定したテンプレートです。論文誌に投稿する際などは適宜 documentclass のオプションを変更してください。

## 内容

- IEEEtran.cls: IEEE IES の論文フォーマットのクラスファイル
- IEEEtran_HOWTO.pdf: IEEEtranのクラスの使い方(必読)
- IEEEtran_hflab.pdf: サンプルのコンパイル結果(例)
- IEEEtran_hflab.tex: 学会投稿論文のサンプル

## 参考

- IEEE IES 公式の最新のテンプレートは [Manuscript Templates for Conference Proceedings](https://www.ieee.org/conferences/publishing/templates.html) からダウンロードしてください。
- フォーマットについての詳しい説明は [Paper Format for Conferences](http://www.ieee-ies.org/conferences/paper-format-for-conferences)
 から確認してください。
- IEEE Control System Society (CSS) はフォーマットが異なりますので[こちら](http://css.paperplaza.net/conferences/support/tex.php)からテンプレートをダウンロードしてください。
